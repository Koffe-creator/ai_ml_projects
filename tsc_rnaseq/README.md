# scRNA-seq Analysis Pipeline

A full single-cell RNA-seq analysis pipeline applied to a simulated PBMC-like dataset, covering everything from QC filtering through Harmony batch correction to differential expression.

## Scripts

### `Misc/simulation.py`
Simulates a realistic 10x Chromium scRNA-seq count matrix with:
- 6 immune cell types (CD4_T, CD8_T, B_cell, NK_cell, Mono_Classical, DendriticCell)
- Negative Binomial count distribution (dispersion = 5) to match real 10x overdispersion
- 4 donor batches with multiplicative library-size and gene-level noise
- 2 conditions (Control / Treatment) with a simulated treatment effect on 25 genes
- Intentional QC outliers: Doublets, Dying cells, Empty droplets

Run this first to generate `Output/simulated_counts_raw.h5ad`.

### `analysis.py`
Full pipeline modelled after published PBMC studies:

| Step | Method |
|---|---|
| QC metrics | `scanpy.pp.calculate_qc_metrics` |
| Filtering | n_genes, n_counts, % MT thresholds |
| Normalisation | Total count normalisation + log1p |
| HVG selection | Seurat method, 2,000 genes, batch-aware |
| PCA | 50 PCs |
| Batch correction | Harmony (donor-level) |
| Clustering | k-NN graph → Leiden (resolution 0.5) |
| Visualisation | UMAP (6-panel overview) |
| Cell type annotation | Canonical marker dotplot + majority-vote |
| Differential expression | Wilcoxon rank-sum, FDR-BH correction |
| Composition | Stacked bar plots by condition and donor |

## Output
All figures and results are saved to `Output/` (not tracked in git — regenerated by running the scripts).

## Requirements

```bash
pip install scanpy harmonypy anndata scipy statsmodels matplotlib seaborn pandas numpy
```

## Usage

```bash
# Step 1 — generate simulated data
python Misc/simulation.py

# Step 2 — run the analysis
python analysis.py
```
